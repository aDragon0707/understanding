# Lijie Skill 中文介绍

`lijie` 是一个帮助 AI 助手把知识讲清楚、拆明白、画出结构的 Codex skill。

它适合处理概念、文章、课程、论文、工作流、技术系统、商业模型、思维模型和陌生领域。普通摘要通常只会压缩文字，而 `lijie` 的重点是把知识变成可以学习、复述、迁移和自测的结构。

## 核心作用

1. 费曼解释：先用简单语言讲清楚，再给出精确版本。
2. 第一性原理拆解：区分底层概念、事实、假设、机制、限制、结果和例子。
3. 知识结构映射：标出顺序、并列、层级、依赖、一对多、多对一、网络、闭环和开环。
4. 掌握检查：通过复述题、应用题、比较题和诊断题验证是不是真的理解。

## 它解决的问题

很多学习材料的问题不是“太长”，而是“关系不清”。读者可能知道很多点，却不知道：

- 哪些是前提，哪些是结论
- 哪些是组成部分，哪些是执行步骤
- 哪些概念互相依赖
- 哪些解释缺少反馈和验证
- 哪些地方只是熟悉感，不是真掌握

`lijie` 的目标就是把这些隐藏关系显式化。

## 一句话介绍

`lijie` 把陌生知识从“看过了”变成“讲得出、拆得开、用得上、能验证”。
