# Lijie Skill Introduction

`lijie` is a Codex skill for helping an AI assistant explain, decompose, and map knowledge.

It is useful for concepts, articles, courses, papers, workflows, technical systems, business models, mental models, and unfamiliar domains. Instead of only shortening source material, `lijie` turns information into a structure that can be learned, recalled, transferred, and tested.

## Core Functions

1. Feynman explanation: explain simply first, then precisely.
2. First-principles decomposition: separate primitives, facts, assumptions, mechanisms, constraints, consequences, and examples.
3. Knowledge-structure mapping: label sequences, parallel sets, hierarchies, dependencies, one-to-many, many-to-one, networks, closed loops, and open loops.
4. Mastery checks: verify understanding through explain, apply, compare, and diagnose prompts.

## Problem It Solves

Many learning materials are not just too long. They are structurally unclear. A learner may know many points but still not know:

- which points are prerequisites and which are conclusions
- which items are components and which are process steps
- which concepts depend on each other
- which explanations lack feedback or validation
- where familiarity is being mistaken for mastery

`lijie` makes those hidden relationships explicit.

## One-Line Description

`lijie` turns unfamiliar knowledge from "I have seen it" into "I can explain it, decompose it, use it, and test it."
