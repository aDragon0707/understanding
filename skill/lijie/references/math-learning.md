# 数学学习适配器

本文件用于学习数学定义、对象、运算、命题、推导、证明和反例。它不替代具体教材，也不允许用直觉类比冒充证明。

## 适配范围

优先处理：

- 理解定义及其必要条件；
- 从例子抽象结构，或从定义推出结果；
- 计算、推导、证明和构造反例；
- 比较相似概念；
- 改变条件后重新判断结论；
- 识别证明中的隐藏跳步。

## 学科拆解

### Objects

数、集合、函数、关系、空间、结构、命题、证明和算法。

### Primitives

定义、符号、量词、逻辑连接、相等关系、基础运算和必要前置定理。

### Operations

代数变换、构造、分解、归纳、演绎、反证、分类讨论、估计、取极限和比较。

### Representations

根据目标建立必要转换：

```text
具体例子 ↔ 图像/几何直觉 ↔ 符号表达 ↔ 定义/定理 ↔ 证明或计算
```

指出每种表示保持了什么，又遗漏了什么。类比只能建立直觉，不能替代定义和证明义务。

### Assumptions and Invariants

明确：

- 变量的定义域和值域；
- 必要条件、充分条件和等价条件；
- 运算是否合法；
- 变换过程中保持的性质；
- 结论依赖哪些假设；
- 极端值、空集、零、负数、无穷和退化情况。

### Evidence

根据目标选择：

- 从定义判断例子和非例子；
- 在不看原文时解释每个条件的作用；
- 完成一段缺失推导；
- 找到证明中的非法跳步；
- 构造反例；
- 独立完成计算或证明；
- 改变一个假设后重新判断结论；
- 把同一结构迁移到不同表面问题。

## 推荐工作流

不存在唯一固定顺序。根据校准选择：

### 从具体到抽象

```text
例子和非例子
→ 找共同结构
→ 提炼定义
→ 解释每个条件
→ 推导结论
→ 构造边界和反例
```

### 从定义到推导

```text
定义/公理
→ 展开量词和条件
→ 确定允许的操作
→ 建立局部引理
→ 推出结论
→ 检查条件改变后的结果
```

### 从矛盾到模型

```text
发现不一致或反直觉现象
→ 提出候选解释
→ 推导可检查后果
→ 用例子、证明或反例裁决
```

## 常见错误模型

- 背诵定义但不知道每个条件排除了什么；
- 把必要条件当充分条件；
- 根据几个例子直接断言普遍结论；
- 在推导中除以可能为零的量；
- 偷换变量范围、量词或符号含义；
- 用图像直觉替代证明；
- 只会模仿同型题，条件稍变就失效；
- 把计算正确误认为概念和证明均已掌握。

## 迁移任务

优先改变一个结构性条件：

- 删除或反转一个假设；
- 改变定义域或边界条件；
- 从有限推广到无限，或反过来；
- 从具体数值转到参数；
- 要求证明原命题、逆命题或否命题；
- 要求构造最小反例；
- 将同一结构换成几何、代数或概率表示。

## 结束标准

至少检查定义理解、条件边界和一个独立推导、反例或迁移任务。只会复述定理或模仿例题，不能判定为 `transferable`。
